# MenuConnect
Demo independiente de MenuConnect by Marketing Connect, preparada para GitHub y Cloudflare.

Incluye selector Básico/Premium, demo Coffee CLUB, categorías, búsqueda, 18 productos Premium, personalización, carrito, total, nombre del comensal, número de mesa, indicaciones y generación del pedido por WhatsApp. El plan Básico muestra 12 productos en esta demo y contacto directo por WhatsApp.
